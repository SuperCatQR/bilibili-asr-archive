# Security reports

Report exploitable vulnerabilities privately through the repository's
[security advisory form](https://github.com/SuperCatQR/bilibili-asr-archive/security/advisories/new).
Include the affected commit/version, a minimal synthetic reproduction, impact,
and suggested mitigation. Do not include working credentials, third-party media,
signed URLs, or private archive contents in public issues.

Rotate any exposed credential at its provider immediately; deleting a Git commit
does not revoke a credential. Review dependency and secret-scanning alerts and
keep fixes as focused PRs with their lockfile and verification evidence.
