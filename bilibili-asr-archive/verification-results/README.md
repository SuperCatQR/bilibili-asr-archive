# Verification result artifacts

From the package root, the local green/red check is `python -m pytest -q` with
Python 3.12. Provision the test interpreter first with
`python -m pip install --upgrade pip setuptools wheel` and
`python -m pip install -e ".[dev]"`. The console-script tests build and install
a separate local wheel without downloading dependencies; they do not depend
on a developer console script or a cached uv build backend. Default runs skip
the live network, GPU, scale and unavailable harness-engine lanes; skips do
not verify those capabilities. CI runs this same product suite.

The focused smoke lane in the README is useful during development. The
offline wheel corpus and advisory snapshot required by `verify_baseline.py`
remain the release verification lane; the local pytest command does not
claim that release-grade dependency audit.

`baseline.json` is generated by `scripts/verify_baseline.py`. It contains only
command names, return codes, policy, status, and a bounded redacted error. Do
not commit generated results. The repository ignores `baseline.json` so CI may
publish it as a short machine-readable artifact without including environment
variables, credentials, model files, media, raw subprocess output, or archive
contents.
